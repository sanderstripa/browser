# Internet Browser

Минималистичный браузер на Chromium/Electron для Windows со встроенным VPN на базе Xray.

## Версия 0.6.0

- два оформления верхней панели: классическое и компактное;
- классическая панель стала ниже и плотнее, адресная строка и вкладки получили более мягкие скругления и состояния;
- кнопка новой вкладки в классическом режиме находится рядом с вкладками;
- компактный режим повторно собран как одна непрерывная строка: вкладки и действия являются прямыми элементами общей панели;
- опциональная матовая полупрозрачность панели включается отдельно в настройках;
- адресная строка умеет открывать переход в текущей вкладке либо в новой, когда текущая занята;
- исправлено перетаскивание безрамочного окна за верхнюю кромку панели;
- Windows-приложение и ярлыки используют отдельную крупную иконку без внешнего ореола; иконка установщика сохранена;
- включён ускоренный графический путь Chromium для тяжёлых страниц и видео;
- вкладки, временная боковая панель, история, избранное и загрузки;
- подсказки адресной строки из открытых вкладок, истории, избранного и поисковой системы;
- встроенный VPN сохранён без изменения архитектуры;
- светлая, тёмная и системная темы;
- русский и английский языки;
- обычный Windows-установщик с выбором папки, ярлыками и удалением через систему.

## Сборка

Требуются Node.js 22+ и Windows либо среда, способная собирать Windows-приложения Electron.

```powershell
npm ci
npm run setup:vpn
npm run build:installer
```

Готовый файл появится в папке `release`.

## Пользовательские данные

История, закладки, пароли, настройки браузера и VPN не входят в репозиторий. В установленной версии они хранятся в стандартной папке данных приложения Windows.

## Расширения Chrome

Electron использует Chromium, но не гарантирует совместимость со всеми расширениями Chrome. VPN интегрирован непосредственно в браузер.

Проект распространяется без предоставления лицензии на повторное использование.
